# Viewsdatabase

## Alcance centrado en planificaciones semanales
El sistema conserva los roles SUPERADMIN, ADMIN y DOCENTE y los módulos necesarios para materias, asignaciones, horarios, recreos y planificaciones semanales. No reintroducir asistencias, justificaciones, notas, boletines, estudiantes, matrículas, tutorías ni el rol SUBINSPECTORA salvo una nueva decisión explícita del proyecto.
